# Week 2 - Linux Command-Line Practice

Complete as many levels of the OverTheWire Bandit wargame as possible during the practical session.

The purpose of this exercise is to practise:

- connecting to a Linux server using SSH;
- navigating directories and working with files;
- identifying file types and properties;
- searching for files and text;
- combining commands using pipes.

There is no required target level or ranking. Work at your own pace.

Before starting:

1. ensure that an SSH client is available on your computer;
2. read the OverTheWire rules in full and accept them on the website;
3. open the Bandit page and follow the instructions for the starting level.
